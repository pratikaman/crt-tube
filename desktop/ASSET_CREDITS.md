# Macintosh scene

`assets/macintosh-plus-render.png` is a rendered view of **Personal Computer
"Macintosh Plus", 3-teilig**, by **Deutsches Museum | Digital**.

- Original model: https://sketchfab.com/3d-models/64319e3fd7dd44acb7d6d72cd8c395db
- Museum collection record: https://digital.deutsches-museum.de/item/2000-468/
- Model inventory number: 2000-468
- License: **Creative Commons Attribution-ShareAlike 4.0 International**
  (https://creativecommons.org/licenses/by-sa/4.0/)
- Changes: rendered through the Sketchfab Viewer API at 3840 × 2160 with a transparent
  background, saved as PNG, framed in the app with CSS, and overlaid with the
  interactive YouTube view. The rendered image remains under CC BY-SA 4.0.
- Render obtained September 29, 2026.

The image is bundled locally. No Sketchfab connection or model download is needed
to display the computer in the application. This is a fixed rendered view, not an
orbitable live 3D viewer.

The Macintosh and Apple marks are part of the depicted museum object. CRT Tube is
an independent application, not an Apple or Deutsches Museum product.

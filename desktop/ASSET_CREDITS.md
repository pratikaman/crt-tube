# Macintosh scene

`assets/macintosh-plus.glb` is the original downloadable scan of the same museum
object used for the image below, including its keyboard, mouse, and textures.

- Download: https://media.deutsches-museum.de/3d/2000-468/2000-468_001_P91K_T4K.glb
- Source: https://digital.deutsches-museum.de/item/2000-468/
- Creator: **Deutsches Museum | Digital**
- License: **CC BY-SA 4.0**, https://creativecommons.org/licenses/by-sa/4.0/
- File downloaded October 2, 2026; bundled unchanged. The app positions and lights
  the scan at runtime and projects a screen preview onto its existing glass.
- Rendered with Three.js (MIT); see `THREE-LICENSE.txt` for the full notice.

The normal player retains the original image and UI. The TV menu or `⌘⇧3`
opens the live 3D scan; drag or use arrow keys to rotate, `Home` resets its angle,
and `Esc` or a double-click returns to the existing screen. Both assets load
locally without a Sketchfab connection.

`assets/macintosh-plus-render.png` is a rendered view of **Personal Computer
"Macintosh Plus", 3-teilig**, by **Deutsches Museum | Digital**.

- Original model: https://sketchfab.com/3d-models/64319e3fd7dd44acb7d6d72cd8c395db
- Museum collection record: https://digital.deutsches-museum.de/item/2000-468/
- Model inventory number: 2000-468
- License: **Creative Commons Attribution-ShareAlike 4.0 International**
  (https://creativecommons.org/licenses/by-sa/4.0/)
- Changes: rendered through the Sketchfab Viewer API at 3840 × 2160 with a transparent
  background, saved as PNG, framed in the app with CSS, and overlaid with the
  interactive YouTube view. The rendered image remains under CC BY-SA 4.0.
- Render obtained September 29, 2026.

The image is bundled locally and remains the fixed front view for direct YouTube
interaction. The separate GLB above supplies rotation without replacing the asset.

The Macintosh and Apple marks are part of the depicted museum object. CRT Tube is
an independent application, not an Apple or Deutsches Museum product.
